其他

连不上？

卡片用的是 Nordic UART Service（NUS），蓝牙调试工具的事实标准： 服务 6E400001-B5A3-F393-E0A9-E50E24DCCA9E， 写特征值 6E400002-…，通知特征值 6E400003-…， 广播名 Passport。nRF Connect、LightBlue、Serial Bluetooth Terminal 都能直接写。

线上格式是「长度前缀 + 帧」，例如发一条待办 0x15 写成十六进制是 03 02 15；发一个词 apple / 苹果 是 0F 07 00 05 06 61 70 70 6C 65 E8 8B B9 E6 9E 9C。多字节整数是小端。

找不到设备：卡片上的窗口关了，长按下键重开。连上却发不动：窗口到点断开了，重开再连。 iPhone 的 Safari 没有 Web Bluetooth。
